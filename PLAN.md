# PLAN — rpg-npc-dialogue-engine

## Architecture & Goals
1. Model NPC persona, emotional state, short-term memory, and world state.
2. Build deterministic state transitions based on player triggers and reputation.
3. Construct template-based dialogue engine with role and mood matrices.
4. Implement interactive CLI game loop and REST API server.
5. Create 20+ test suite verifying all state transitions, memory recall, and generation paths.
